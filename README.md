# Yarn Playground

Interactive Yarn Spinner script editor and visualizer. Powered by the official **Yarn Spinner 3.0 C# compiler** via .NET 10 WebAssembly.

![React](https://img.shields.io/badge/React-19-blue)
![Vite](https://img.shields.io/badge/Vite-7-yellow)
![WebAssembly](https://img.shields.io/badge/.NET_10-WebAssembly-success)

## Features

- **Monaco Editor** with Yarn syntax highlighting
- **Visual Node Graph** using React Flow + Dagre auto-layout
- **Interactive Runner** with variable tracking
- **Native Parsing** via official C# Yarn Spinner WebAssembly

## Quick Start

```bash
pnpm install
pnpm dev
```

Open http://localhost:5173

## Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- React Flow
- .NET 10 WebAssembly (Yarn Spinner 3.0.2)
